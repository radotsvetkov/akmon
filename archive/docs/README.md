# Archived handbook pages

These pages documented features that were removed from the Akmon build in v3.0.0
(context import/export, the spec workflow, semantic search, SLO metrics, and the
`akmon sign` external signing hook). They are kept for history only and are not
part of the published handbook. Links inside them may point at pages that no
longer exist.

The code they describe is under `archive/` and in the tag `archive/pre-focus-v2.2.1`.
For signing, use [`akmon bundle sign`](../../docs/src/reference/bundle-sign.md) or
[`akmon seal`](../../docs/src/reference/seal.md).
